# Security Policy

RouteIQ takes the security of municipal infrastructure databases seriously. 

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

Please do not report security vulnerabilities via public GitHub issues. Instead, email security reports to `security@routeiq-enterprise.gov`.

Include:
- Summary of the vulnerability.
- Steps to reproduce.
- Potential impact on municipal road registries or auth tokens.

We aim to acknowledge reports within 48 hours and provide patches within 14 days.
